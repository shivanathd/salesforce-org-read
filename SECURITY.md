# Security policy

Found a security problem in this plugin, for example a way it could change an org, leak a login or run something it should not? Email **apps@mindcat.ai**. Please don't open a public GitHub issue for it.

Include what you saw, the steps to reproduce it, and the plugin version. Never send passwords, access tokens or org data; a description is enough.

We will reply to confirm we have it, and say what we will do about it.
